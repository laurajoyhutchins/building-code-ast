# IBC 2018 structural corpus

This directory contains the source-safe 2018 IBC structural inventory bound to SHA-256 `c8f0b75522707a39daf5202edee25d7fdce6c177c382f828a6dc1dfd5cc0b18d`.

The corpus records structure, provenance, review state, and constrained interpretation metadata. It does not contain the PDF, page images, full code text, complete table contents, or a compliance model.

Start with:

- `ibc-2018-source-manifest.json` and `ibc-2018-source-register.json` for exact source identity;
- `ibc-2018-corpus-manifest.json` for versioned counts and correction history;
- `ibc-2018-coverage-report.md` for current totals;
- `ibc-2018-counting-policy.md` for count units and edge cases;
- `ibc-2018-discrepancies.md`, `ibc-2018-review-queue.csv`, and `ibc-2018-review-summary.md` for prioritized review work;
- `ibc-2018-semantic-review-packet.md` for the 27-record human sign-off pilot;
- `ibc-2018-vector-region-inventory.json` and its summary for vector-path review candidates;
- `ibc-2018-reference-map.md` and `ibc-2018-reference-crosschecks.json` for reconciled internal and external-reference relationships.

All initial expected counts remain provisional unless an item says otherwise.
