# IBC 2018 counting policy 0.1.0

- Count one logical table or figure per published identifier. Preserve every caption occurrence as an anchor.
- Merge explicit continuation pages into the logical record. Do not count repeated headers as new structures.
- Reject table-looking labels embedded within a figure as independent tables.
- Count broad incidental layouts by aligned geometry. Count strict layouts only when recurring columns and row structure are stronger. Exclude ordinary page columns and navigation typography.
- Count one equation per displayed primary formula block. Attach continuations, variable definitions, and applicability lines. Exclude prose measurements, table cells, figure labels, and external-standard designations.
- Count one exception block per explicit `Exception:` or `Exceptions:` marker. Keep numbered children nested.
- Count each Chapter 35 row separately from each distinct observed designation, normalized family, and citation occurrence.
- Include appendices with appendix context. Exclude the subject index from code-body structure totals.
- Preserve front matter for source mapping, but do not count its navigation layouts as code tables.
- Keep all disputed and rejected detections. Do not silently delete borderline evidence.
