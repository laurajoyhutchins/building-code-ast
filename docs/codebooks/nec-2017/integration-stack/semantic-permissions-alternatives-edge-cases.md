# NEC semantic coverage: permissions, alternatives, and edge cases

Predecessor: `feature/nec-semantic-review-queue`.

Owns:
- reviewed coverage for permissions, prohibitions, nonrequirements, alternatives, approval-dependent language, nested/multiple exceptions, definition-heavy clauses, cross-reference-heavy clauses, and other language shapes that do not fit the simpler coverage lanes;
- explicit logical grouping and alternative ownership with unresolved states rather than guessed conjunctions;
- counterexamples for parser/review disagreement and remaining generic semantic gaps;
- calibrated support claims for difficult clause families.

Does not own:
- treating authority approval as a project decision;
- guessing OR/AND grouping from punctuation alone;
- swallowing unsupported language into generic prose fields;
- compliance evaluation.

Completion:
- difficult modality/alternative/exception/reference archetypes have representative reviewed coverage;
- accepted semantics preserve logical ownership, conditions, dependencies, and provenance;
- unsupported or ambiguous grouping remains explicit;
- remaining gaps are measurable inputs to final semantic closeout rather than hidden parser failures.

Sibling successors: other semantic-archetype coverage lanes; all converge at semantic coverage closeout.
