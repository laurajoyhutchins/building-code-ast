# NEC semantic coverage: table selection and sizing

Predecessor: `feature/nec-semantic-review-queue`.

Owns:
- deliberate reviewed coverage across NEC table families that select or size requirements from classified inputs;
- reuse and measured extension of the generic table lookup contract proven by 110.26;
- semantic header/span roles, units, qualifications, table footnotes, continuation ownership, and derivation provenance where reviewed;
- explicit unsupported states for table forms that cannot yet be represented honestly.

Does not own:
- automatic semantic interpretation of every structurally recognized table;
- engineering solvers that invent inputs or make design decisions;
- figure/diagram semantics;
- project compliance evaluation.

Completion:
- representative lookup/sizing table archetypes across multiple NEC articles are reviewed and measured;
- accepted table-derived values retain complete selection provenance;
- ambiguous header/footnote/continuation meaning blocks promotion;
- unsupported table families remain visible in the review queue.

Sibling successors: other semantic-archetype coverage lanes; all converge at semantic coverage closeout.
