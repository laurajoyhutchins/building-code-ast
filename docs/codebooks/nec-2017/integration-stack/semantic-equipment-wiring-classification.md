# NEC semantic coverage: equipment, wiring, and classification

Predecessor: `feature/nec-semantic-review-queue`.

Owns:
- reviewed coverage for equipment characteristics, conductor/wiring-method constraints, listing/labeling/marking requirements, motor/equipment rule shapes, and classification-driven requirements including hazardous-location families;
- explicit class/category membership evidence and conditional constraints without treating labels as universal ontology facts;
- definition/reference dependencies and unresolved classifications where needed;
- measured counterexamples across multiple NEC articles.

Does not own:
- manufacturer-product evaluation;
- determining whether a real installation satisfies a classification;
- importing external listing standards or product data;
- project compliance evaluation.

Completion:
- representative classification- and equipment-driven rule archetypes are reviewed and measurable;
- accepted semantics preserve class conditions, required properties/actions, dependencies, exceptions, and provenance;
- unresolved taxonomy or source relationships remain explicit;
- semantic vocabulary stays generic where the concepts are publication-independent.

Sibling successors: other semantic-archetype coverage lanes; all converge at semantic coverage closeout.
