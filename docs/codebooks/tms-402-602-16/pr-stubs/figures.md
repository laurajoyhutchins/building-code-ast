# TMS 402-16 figures and graphical regions

Status: draft PR scaffold; implementation not started.

## Purpose

Preserve TMS 402 figures and other graphical source regions as explicit structural evidence without inferring masonry geometry or engineering meaning.

## Scope

- figure identity, captions, labels, and parent relationships
- graphical-region source coordinates and OCR/image provenance
- figure references and nearby notes where source-backed
- component/source-role ownership
- explicit unsupported graphical semantics
- measured exact-source coverage against the structural inventory

## Boundaries

Do not infer dimensions, construction requirements, masonry geometry, or compliance meaning from graphics without a separately reviewed graphical semantic contract.

## Completion gate

Measured TMS 402 figure/graphical regions have stable identity, provenance, ownership, and explicit supported/unsupported state. Remove this scaffold file when implementation replaces it.
