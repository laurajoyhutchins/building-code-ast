# TMS 402-16 applicability and provision semantics

Status: draft PR scaffold; implementation not started.

## Purpose

Map selected normative TMS 402 provisions into shared semantic contracts for requirement/prohibition/permission, actions, conditions, alternatives, exceptions, and scoped applicability.

## Scope

- normative-effect candidates linked to exact structural evidence
- subject/action/condition/exception structure
- recursive logical conditions and numeric comparisons where source-backed
- scoped applicability relationships within the publication
- links to reviewed definitions/references/equations/tables as dependencies
- explicit unsupported/ambiguous semantic cases

## Boundaries

Do not decide project facts, AHJ applicability, code adoption, masonry design compliance, or treat commentary as governing evidence.

## Completion gate

Selected contrasting TMS 402 normative provision families have reviewed semantic representations with exact provenance and explicit unsupported/ambiguous states. Remove this scaffold file when implementation replaces it.
