# IBC 2018 official-copy reconciliation

Base: current `main`. This is an evidence lane parallel to the semantic integration stack.

Owns:
- independent comparison of the exact processed IBC artifact against an independently obtained official publisher copy;
- provenance, hashes, page count, edition metadata, and factual difference reporting;
- explicit handling of any discrepancy without silently replacing the existing source identity.

Does not own:
- committing the PDF or reconstructive source material;
- semantic interpretation;
- blocking unrelated contract work when the existing exact-source identity is sufficient;
- compliance conclusions.

Completion:
- independently obtained official-copy provenance is documented locally and source-safe facts are recorded publicly where permitted;
- exact identity comparison is reproducible;
- byte/content differences, if any, are explicit and reconciled before final IBC support claims;
- the current processed artifact identity is never silently substituted.

Relationship to main stack: evidence-strengthening lane; material discrepancies must be reconciled before final integration closeout.
