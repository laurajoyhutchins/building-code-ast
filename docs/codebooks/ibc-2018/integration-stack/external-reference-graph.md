# IBC 2018 external reference graph

Predecessor: `feature/ibc-calculation-semantics`.

Owns:
- Chapter 35 and external-standard relationships projected into the provenance graph;
- designation, edition, family/alias identity, source evidence, and unresolved matches;
- clear separation between a publication reference and any downstream applicability decision.

Does not own:
- importing external-standard text;
- determining whether a project must comply with a referenced standard;
- adoption, jurisdiction, or compliance conclusions.

Completion:
- existing Chapter 35 and external citation inventories project deterministically;
- matched, unmatched, ambiguous, and alias-resolved relationships remain explicit;
- graph edges retain exact IBC source evidence;
- no external text is copied into IBC graph nodes.

Successor: `feature/ibc-semantic-review-workflow`.
