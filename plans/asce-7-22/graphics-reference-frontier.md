# ASCE 7-22 graphical reference and support frontier

Scope-only terminal graphics lane.

## Owns
- references from provisions to figures/maps/graphical regions
- structural relationships among captions, legends, labels, and graphical regions
- explicit support matrix for graphical families
- reviewed declaration of which graphical semantics remain unsupported
- invariant that printed maps are not silently replaced by current external services

## Does not own
- site-specific hazard determination
- inferred contour/region engineering values without a reviewed representation

## Successor
`feature/asce-7-22-semantic-candidates` consumes references but does not require graphical semantic completion.
